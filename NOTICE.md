## osrs-dps-calc

The combat calculation engine in `com.github.diogogdias.bisfinder.calc` is a Java port of the
OSRS Wiki DPS calculator by Weird Gloop.

- Source: https://github.com/weirdgloop/osrs-dps-calc
- License: GNU General Public License v3.0

The item and monster data files fetched at runtime
(`cdn/json/equipment.json`, `cdn/json/monsters.json`) come from the same project.

Because that work is licensed under the GPL-3.0, this plugin is distributed under the GPL-3.0 as
well. See `LICENSE`.

Weird Gloop credits Bitterkoekje's spreadsheet for much of the underlying combat maths.
